# Chalex Motel

## Onde encontrar os arquivos

- `index.html` — página inicial e escolha da unidade.
- `center/index.html` — página da unidade Center, Bezerra de Menezes.
- `country/index.html` — página da unidade Country, Messejana.
- `css/style.css` — estilos e layout responsivo.
- `js/home.js` — cartões das unidades na página inicial.
- `js/suite-page.js` — catálogo, preços, carrossel e reservas da Center.
- `img/` — logos e fotos organizadas por suíte.
- `docs/Informacoes_Chalex.md` — endereços, contatos e links de referência.

Abra `index.html` para começar. Os links das unidades abrem as páginas em `center/` e `country/`.
